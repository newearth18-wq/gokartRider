# Turbo Trail

เกมแข่งโกคาร์ต 3D ต้นฉบับในแนวภาพการ์ตูนสดใส เล่นได้บนมือถือ แท็บเล็ต และคอม ตัวละคร สนาม และภาพในเกมออกแบบใหม่ ไม่ใช้ไฟล์ของ KartRider Rush+

## เล่นเกม

เปิด [เกมบน GitHub Pages](https://newearth18-wq.github.io/gokartRider/) เลือกนักขับ รุ่นรถ สนาม และโหมด แล้วเล่นคนเดียวหรือสร้างห้องออนไลน์ได้ ห้องหนึ่งรองรับผู้เล่นจริงสูงสุด **50 คน** แชร์รหัสห้อง 5 ตัวให้เพื่อนเข้าร่วม เจ้าของห้องเป็นผู้เริ่มการแข่งขัน

### เข้าห้องเรียนด้วย QR

ครูเลือก **แข่งออนไลน์ → สร้างห้อง 50 คน** แล้วฉาย QR ในหน้าห้อง (กด **ขยาย QR** เพื่อแสดงเต็มจอ) นักเรียนเปิดแอปกล้องมือถือสแกน QR ลิงก์จะเปิดหน้าเลือกตัวละครและแต่งรถ พร้อมกรอกรหัสห้องและชื่อชั่วคราวให้ จากนั้นนักเรียนกด **เข้าห้องนี้** เอง สามารถคัดลอกลิงก์หรือกรอกรหัสห้อง 5 ตัวแทนได้ ในเบราว์เซอร์ที่รองรับ BarcodeDetector ยังมีปุ่ม **สแกน QR เพื่อเข้าห้อง** ภายในเกมด้วย หากไม่รองรับให้ใช้แอปกล้องของเครื่อง ผู้เข้าร่วมต้องเข้าก่อนครูกดเริ่มแข่ง และห้องจำกัดที่ 50 คนตามเซิร์ฟเวอร์

### เนื้อหาปัจจุบัน

- นักขับต้นฉบับ 10 คน: โนวา, ป๊อปปี้, ริโก้, โมโม่, ลูน่า, มินต์, บีบี, พิกเซล, โคโค่, โซล
- รถ 7 รุ่นที่มีรูปทรงและสมรรถนะต่างกัน: คอมเม็ตสปอร์ตเปิดประทุน, ร็อกเก็ตปีกคู่และท่อเจ็ต, กริปเปอร์รถลุยล้อโต, แฟลชทรงสูตรหนึ่ง, บับเบิลโดมกลม, ชาร์ครถฉลามครีบสูง และโฮเวอร์ยานลอย ทุกคันมีแท่นติดอาวุธและแต่งสีรถ หมวก ล้อ ลายรถได้
- สนาม 4 ธีม: สวนสายรุ้ง, หุบเขาทอง, ยอดเขาหิมะ, เมืองริมอ่าว
- เส้นทางยาวขึ้นจากเวอร์ชันก่อนอีกประมาณ 39% ถนนกว้างขึ้น 40% และวางภูเขา บ้าน ต้นไม้กับของตกแต่งนอกถนน
- สปีดเรซและไอเท็มเรซ (ไนโตร, โล่, คลื่นพลัง, เปลือกกล้วย, ลูกบอลเด้ง, พายครีม)
- แข่ง 4 รอบ, ดริฟต์ชาร์จบูสต์, อันดับ, เวลา, แผนที่, คู่แข่ง AI ในโหมดเล่นคนเดียว
- ห้องออนไลน์ WebSocket พร้อมตำแหน่งรถแบบสด และขีดจำกัด 50 คนต่อห้อง
- โหมดเรียนรู้: คำถาม 4 ตัวเลือกเปิดเป็นหน้าต่างกลางจอ รถหยุดชั่วคราว ตอบถูกแล้วได้รับพลังหนึ่งชนิดจาก 6 ชนิด รางวัลมีการ์ดและปุ่มใช้พลังบนหน้าจอ ไอเท็มที่ถือจะปรากฏบนแท่นหลังรถ
- เปลือกกล้วยวางดักรถที่ตามมา ลูกบอลเด้งและพายครีมยิงเป้าหมายใกล้ตัว ทำให้คู่แข่งช้าลงชั่วคราว เกราะป้องกันกันการโจมตีได้ ในห้องออนไลน์เซิร์ฟเวอร์เลือกเป้าหมายและกระจายเหตุการณ์ให้ผู้เล่นเห็นตรงกัน
- เพลงพื้นหลังจังหวะเกมแข่ง พร้อมเสียงเครื่องยนต์ นับถอยหลัง บูสต์ พลัง คำตอบ และเส้นชัย สร้างด้วย Web Audio; ปุ่มลำโพงเปิดหรือปิดเสียงได้ เพลงเริ่มหลังผู้เล่นกดเริ่มแข่งตามกฎของเบราว์เซอร์
- ต้องเลี้ยวรับโค้งด้วยตัวเอง การกดเร่งอย่างเดียวทำให้รถไถลไปชนขอบและเสียความเร็ว รถที่ชนขอบยังเลี้ยวกลับเข้าถนนและเร่งออกตัวได้

## จัดการข้อสอบ

กด **จัดการข้อสอบ** บนหน้าเมนูเพื่อเพิ่ม แก้ หรือลบคำถาม (ได้ 1–20 ข้อ) เลือกเฉลยและกด **บันทึกข้อสอบ** ข้อสอบจะถูกเก็บในเบราว์เซอร์ของเครื่องนั้น เมื่อต้องการย้ายเครื่องให้ใช้ **ส่งออก JSON** และ **นำเข้า JSON** หากสร้างห้องออนไลน์ ชุดข้อสอบของเจ้าของห้องจะส่งให้ผู้เล่นทุกคนในห้องโดยอัตโนมัติ

การแข่งขันคนเดียวหยุดเวลาเมื่อคำถามปรากฏ การแข่งออนไลน์ยังนับเวลาแต่รถผู้ตอบหยุด และมีเวลา 20 วินาทีต่อข้อ คำถามและเฉลยของห้องออนไลน์ถูกส่งให้เบราว์เซอร์ผู้เล่นทุกคน จึงเหมาะกับกิจกรรมเรียนรู้แบบไม่ใช้ผลสอบเป็นคะแนนทางการ

## การควบคุม

| อุปกรณ์ | ควบคุม |
| --- | --- |
| คอม | `W` / `↑` เร่ง, `A` / `←` เลี้ยวซ้าย, `D` / `→` เลี้ยวขวา, `Space` ดริฟต์, `Shift` ใช้บูสต์หรือไอเท็ม |
| มือถือและแท็บเล็ต | ลากแป้นเลี้ยว กด GO ค้างเพื่อเร่ง กด DRIFT เข้าโค้ง และกด BOOST เมื่อมีพลัง รถจะไม่ออกตัวเอง |

ระหว่างแข่งกด **อันดับทั้งหมด** เพื่อดูรายชื่อผู้เข้าแข่งโดยไม่ให้ตารางบังสนามตลอดเวลา

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป ไม่มีแพ็กเกจภายนอกที่ต้องติดตั้ง

```sh
node server.js
```

เปิด `http://localhost:3000/` เซิร์ฟเวอร์เดียวกันให้ทั้งหน้าเกมและห้องออนไลน์ รันการทดสอบด้วย `node --test tests/server.test.js tests/quiz.test.mjs tests/driving.test.mjs`

## การเผยแพร่

GitHub Pages เผยแพร่หน้าเกมจาก `main` โดยอัตโนมัติ เซิร์ฟเวอร์ห้องออนไลน์อยู่บน Render โดย `network.js` กำหนด URL ของ WebSocket หลัง deploy แอป Render รัน `node server.js` บนพอร์ตที่บริการกำหนด และมี `/health` สำหรับตรวจสถานะ

ห้องแข่งเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์หนึ่งตัว หากเซิร์ฟเวอร์รีสตาร์ต ห้องและการแข่งขันที่กำลังดำเนินอยู่จะสิ้นสุดลง สถาปัตยกรรมนี้รองรับ 50 คนต่อห้องบนหนึ่ง instance แต่ยังไม่มีบัญชีผู้เล่น ระบบจัดอันดับถาวร หรือการกลับเข้าห้องเดิมหลังหลุด

QR สร้างในเบราว์เซอร์จากลิงก์ห้องโดยตรงด้วยไลบรารี qrcode-generator (MIT; ดู `vendor/QRCODE-LICENSE.txt`) จึงไม่ส่งรหัสห้องไปยังบริการสร้าง QR ภายนอก
