# Turbo Trail

เกมแข่งโกคาร์ต 3D ต้นฉบับในแนวภาพการ์ตูนสดใส เล่นได้บนมือถือ แท็บเล็ต และคอม ตัวละคร สนาม และภาพในเกมออกแบบใหม่ ไม่ใช้ไฟล์ของ KartRider Rush+

## เล่นเกม

เปิด [เกมบน GitHub Pages](https://newearth18-wq.github.io/gokartRider/) เลือกนักขับ สนาม และโหมด แล้วเล่นคนเดียวหรือสร้างห้องออนไลน์ได้ ห้องหนึ่งรองรับผู้เล่นจริงสูงสุด **50 คน** แชร์รหัสห้อง 5 ตัวให้เพื่อนเข้าร่วม เจ้าของห้องเป็นผู้เริ่มการแข่งขัน

### เนื้อหาปัจจุบัน

- นักขับต้นฉบับ 6 คน: โนวา, ป๊อปปี้, ริโก้, โมโม่, ลูน่า, มินต์
- สนาม 4 ธีม: สวนสายรุ้ง, หุบเขาทอง, ยอดเขาหิมะ, เมืองริมอ่าว
- สปีดเรซและไอเท็มเรซ (ไนโตร, โล่, คลื่นพลัง)
- แข่ง 3 รอบ, ดริฟต์ชาร์จบูสต์, อันดับ, เวลา, แผนที่, คู่แข่ง AI ในโหมดเล่นคนเดียว
- ห้องออนไลน์ WebSocket พร้อมตำแหน่งรถแบบสด และขีดจำกัด 50 คนต่อห้อง

## การควบคุม

| อุปกรณ์ | ควบคุม |
| --- | --- |
| คอม | `W` / `↑` เร่ง, `A` / `←` เลี้ยวซ้าย, `D` / `→` เลี้ยวขวา, `Space` ดริฟต์, `Shift` ใช้บูสต์หรือไอเท็ม |
| มือถือและแท็บเล็ต | ปุ่มเลี้ยว, DRIFT, BOOST และ GO บนหน้าจอ รถเร่งอัตโนมัติบนจอสัมผัส |

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป ไม่มีแพ็กเกจภายนอกที่ต้องติดตั้ง

```sh
node server.js
```

เปิด `http://localhost:3000/` เซิร์ฟเวอร์เดียวกันให้ทั้งหน้าเกมและห้องออนไลน์ รันการทดสอบเซิร์ฟเวอร์ด้วย `node --test tests/server.test.js`

## การเผยแพร่

GitHub Pages เผยแพร่หน้าเกมจาก `main` โดยอัตโนมัติ เซิร์ฟเวอร์ห้องออนไลน์อยู่บน Render โดย `network.js` กำหนด URL ของ WebSocket หลัง deploy แอป Render รัน `node server.js` บนพอร์ตที่บริการกำหนด และมี `/health` สำหรับตรวจสถานะ

ห้องแข่งเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์หนึ่งตัว หากเซิร์ฟเวอร์รีสตาร์ต ห้องและการแข่งขันที่กำลังดำเนินอยู่จะสิ้นสุดลง สถาปัตยกรรมนี้รองรับ 50 คนต่อห้องบนหนึ่ง instance แต่ยังไม่มีบัญชีผู้เล่น ระบบจัดอันดับถาวร หรือการกลับเข้าห้องเดิมหลังหลุด
